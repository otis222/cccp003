# CCCP003 — 個人作品集

> 從靈感出發，用程式把想法變成可以體驗的作品。

這是我的個人作品集網站，也是持續探索 Vibe Coding 的實驗基地。我會在這裡整理自己的專案、設計想法與開發紀錄，呈現每個作品如何從概念走向實作，以及過程中的選擇、嘗試與改進。

## 視覺方向

網站走復古未來主義（retro-futurism）路線，靈感來自 1960–70 年代的太空時代印刷品與實驗室儀器：米色紙張、深褐墨色、番茄紅訊號色與四色條紋，搭配半色調網點、類比儀表、收音機調頻刻度與螺絲固定的面板。背景是用 three.js 即時繪製的 3D 測地線球，會隨滑鼠轉動、隨捲動繞行；另有「藍曬」藍圖配色可以切換，深淺色跟隨系統設定。

採用原創版面與視覺元素，不使用遊戲官方標誌、角色或素材；本專案為個人創作，與遊戲官方無關。

## 預計內容

- **首頁｜工作站入口**：個人介紹、創作方向與精選作品。
- **作品｜專案檔案庫**：展示專案背景、實作內容、技術選擇，以及可用的展示與原始碼連結。
- **關於｜開發者檔案**：分享我的興趣、技能與創作方式。
- **紀錄｜開發日誌**：記錄 Vibe Coding 的實驗、問題與解法。
- **聯絡｜交流入口**：提供 GitHub 與後續公開的聯絡方式。

## 製作原則

- 桌面與手機都能流暢瀏覽，保留一致的視覺語言。
- 優先確保文字可讀性、鍵盤操作與清楚的互動狀態。
- 動畫服務於操作與資訊呈現，並支援減少動態效果的偏好。
- 以真實作品與開發過程為核心，持續更新內容。

## 專案狀態

網站已上線：<https://otis222.github.io/cccp003/>

- `index.html`：目前的個人網站，單一 HTML 檔（3D 場景使用 three.js r128）。
- `v1.html`：上一版個人網站，保留作為作品紀錄。
- `game.html`：貪食蛇小遊戲。方向鍵／WASD 往該方向走（手機用十字鍵或在畫面上滑動），按住 Shift 加速；雲端排行榜同一個暱稱只列最高分。

更新頭像、項目連結或聯絡頻道：在網址後加上 `#edit` 開啟站長面板，改好後按「發布到 GitHub」（或「下載 index.html」，再用下載的檔案取代這裡的 `index.html`）。

修改頁面上的文字：在網址後加上 `#dev` 開啟開發者模式（<https://otis222.github.io/cccp003/#dev>），點任何文字就能直接改，Enter 完成、Esc 取消；相同的文字會一起改。改完按工具列的「發布到 GitHub」，大約 1 分鐘後網站就會更新。第一次發布前要先連接 GitHub：照站長面板裡的三個步驟建立一把只能寫入 cccp003 的金鑰（fine-grained token，Contents: Read and write），金鑰只存在那台裝置的瀏覽器。發布時只會改動 index.html 裡的資料區塊，並與 GitHub 上現有的內容合併。工具列的「清單」會列出所有改過的地方，可以逐筆定位或還原；也可以改用「下載 index.html」自己上傳。
