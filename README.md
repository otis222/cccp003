# CCCP003 — 個人作品集

> 從靈感出發，用程式把想法變成可以體驗的作品。

這是我的個人作品集網站，也是持續探索 Vibe Coding 的實驗基地。我會在這裡整理自己的專案、設計想法與開發紀錄，呈現每個作品如何從概念走向實作，以及過程中的選擇、嘗試與改進。

## 視覺方向

網站以《明日方舟：終末地》的工業機能美學為靈感，將作品集想像成一座個人開發工作站：以深灰與黑色建立基底，搭配警示黃、工程格線、模組化區塊與終端機式資訊標記。介面強調清楚的層級、俐落的排版與適度的動態回饋，讓視覺個性與閱讀體驗並存。

採用原創版面與視覺元素，不使用遊戲官方標誌、角色或素材；本專案為個人創作，與遊戲官方無關。

## 預計內容

- **首頁｜工作站入口**：個人介紹、創作方向與精選作品。
- **作品｜專案檔案庫**：展示專案背景、實作內容、技術選擇，以及可用的展示與原始碼連結。
- **關於｜開發者檔案**：分享我的興趣、技能與創作方式。
- **紀錄｜開發日誌**：記錄 Vibe Coding 的實驗、問題與解法。
- **聯絡｜交流入口**：提供 GitHub 與後續公開的聯絡方式。

## 製作原則

- 桌面與手機都能流暢瀏覽，保留一致的視覺語言。
- 優先確保文字可讀性、鍵盤操作與清楚的互動狀態。
- 動畫服務於操作與資訊呈現，並支援減少動態效果的偏好。
- 以真實作品與開發過程為核心，持續更新內容。

目前處於網站規劃階段，尚未完成網站實作與部署。技術選型、啟動方式及線上網址將在實作後補上。
